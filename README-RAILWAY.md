# 🍓 Strawberry Relationship Q&A

این پروژه برای یک وب‌اپ موبایلی Q&A طراحی شده است.

## چیزی که دارد
- صفحه اول با سؤال «دوست داری رابطمون تموم بشه؟»
- مسیر «آره» با تأیید دوباره
- هفت سؤال بله/خیر
- اگر هر جا «نه» انتخاب شود: «به نظر میرسه اطمینان نداری، از اول شروع کن»
- مسیر «نه» در سؤال اصلی
- ذخیره تمام جواب‌ها در PostgreSQL
- پنل مدیریت در `/admin.html`
- آپلود عکس از پنل مدیریت
- طراحی responsive و تم توت‌فرنگی
- متن سؤال‌ها در یک فایل ساده و قابل ویرایش: `public/app.js`

## Deploy روی Railway
1. این پروژه را در GitHub قرار بده یا فایل ZIP را استخراج کن و در یک repository بگذار.
2. در Railway یک Project بساز.
3. یک Service از روی GitHub repository اضافه کن.
4. یک PostgreSQL Database به همان Project اضافه کن.
5. متغیر `ADMIN_PASSWORD` را در Variables سرویس اپ تنظیم کن؛ مثلاً یک رمز طولانی و غیرقابل حدس.
6. Railway معمولاً `DATABASE_URL` را برای سرویس PostgreSQL در اختیار سرویس قرار می‌دهد. اگر در Variables سرویس اپ دیده نشد، Reference مربوط به DATABASE_URL را از PostgreSQL به سرویس اپ اضافه کن.
7. Deploy را انجام بده.
8. لینک عمومی سرویس را باز کن.
9. برای مدیریت جواب‌ها، به `https://YOUR-DOMAIN/admin.html` برو و رمز `ADMIN_PASSWORD` را وارد کن.

## تغییر متن سؤال‌ها
فایل `public/app.js` را باز کن. بالای فایل بخش `questions` را پیدا کن و فقط متن داخل `question` را تغییر بده.

## نکته مهم درباره عکس
برای ساده نگه داشتن پروژه، عکس‌ها به صورت data URL داخل PostgreSQL ذخیره می‌شوند. برای چند عکس شخصی و حجم پایین مناسب است. عکس‌ها را قبل از آپلود به حجم معقول (مثلاً زیر 3 تا 5MB) کاهش بده.

## موزیک
در `public/app.js` مسیر `noPath()` می‌توانی لینک Spotify را با لینک آهنگ دلخواه خودت عوض کنی.
